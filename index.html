Opening開場

This letter is a field guide opening with a question. Suppose an AI system fails: memorised answer when you needed discussion, forgotten decisions, host switch-off. Can people depending on that system still open the system and fix what broke? Every pi-kami choice works toward one answer: yes.

這封信是操作指南，開頭問一問題。假設 AI 系統出狀況：該討論給背好答案、忘了自己決定、託管者關掉。依賴它的人還能自己打開修嗎？pi-kami 每選擇都為讓答案是能。

What this is這是什麼

pi-kami runs ds4-server on your Mac: local inference server (program running the model, answering requests). DeepSeek V4.1 Flash loads once, serves OpenAI API and Anthropic API at 127.0.0.1:8000. Nothing typed leaves the machine. No account, no meter, none of the “sorry, I can’t help with that” gates a hosted service sets.

pi-kami 在你 Mac 跑本機推論伺服器 ds4-server（跑模型、回請求程式）。載 DeepSeek V4.1 Flash，在 127.0.0.1:8000 同時支援 OpenAI 與 Anthropic API。你打每字不離機。不用帳號不計費，沒託管服務替你設的「抱歉，我無法協助」。

pi is the easiest way in, and only one door. Codex CLI, Claude Code, OpenClaw, Hermes Agent: all point at the same server. Each needs one environment variable (startup setting) or a short config block. Chapter 8 shows each setup. Or use pi only as package manager (software installer) and talk to ds4’s native agent: /ds4-agent hands that agent your terminal, returning the terminal when you leave.

pi 是最方便入口，只是其中一扇門。Codex CLI、Claude Code、OpenClaw、Hermes Agent 都連同伺服器，每個只要一環境變數（啟動設定值）或一小段設定，第八章逐一示範。也可只把 pi 當套件管理員（裝軟體工具），改用 ds4 原生智慧體：/ds4-agent 把終端機交智慧體，離開交還 pi。

Why one machine, one stream為什麼是一台機器、一條串流

Hosted services draw speed from batching: one accelerator answers many people at once. Efficiency arrives, audit trail goes. Routing, scheduling, hidden random seeds (starting numbers behind model random choices), tool-call IDs: invisible from outside. pi-kami trades the other way: one machine, one user, one stream. DS4_REPRODUCIBLE=1 sets seed 42 by default, and audreyt/ds4 derives tool-call IDs from that seed. A seeded request returns stable call_… and toolu_… identifiers.

託管服務靠批次換速度：一顆加速器同時答很多人。效率有了，稽核軌跡沒了。路由、排程、藏起的隨機種子（模型隨機選擇起始數字）、工具呼叫 ID，外面都看不見。pi-kami 反取捨：一機、一使用者、一串流。DS4_REPRODUCIBLE=1 預設種子 42，audreyt/ds4 用同種子產工具呼叫 ID，帶種子請求每次回一樣 call_… 與 toolu_…。

Replayable record over right answer. Rerun same input. Diff changed trace (compare two records line by line). Point to one exact tool call. Public decisions, research interviews, procurement, anything surviving contest needs this record kind.

要可重播紀錄。同輸入可重跑，軌跡變了逐行比對（diff），任一工具呼叫可準確指認。公共決策、研究訪談、採購評估，凡得經得起質疑的場合都需要這種紀錄。

v 0.8: a second engine, with earlier releases kept for the recordv 0.8：多一個引擎，舊版紀錄留在後面

Version 0.8.0 renames the extension to pi-kami and adds a second engine. Choose rec/flint in pi and pi-kami runs Flint, Recursive’s open-weight model, on Recursive’s own engine rec, pinned at 0.1.0. ds4/deepseek-v4-flash is still the DeepSeek tier, with the Maya-XS weights from 0.7.3. The runtime names stay as they were: ~/.pi/ds4/ and every DS4_* variable keep their spelling.

Why bring a model home為什麼把模型帶回家

Everything starts from one question behind Software Freedom as Civic Care: when an AI system fails, can inheritors still repair the system? Not vendor, not trainers. Whoever holds the system on the day it stops behaving: newsroom, research group, town office, family.

一切從一問題開始，也是〈軟體自由與公民關懷〉背後問題：AI 系統壞掉，接手人還修得動？不是廠商，也不是訓練者。說系統不聽話那天抱著它的人：編輯室、研究團隊、鄉公所、家庭。要修的是他們。

Running a frontier model on your Mac is the visible part of the answer. A local model you cannot inspect, fork or roll back is a desk cloud service. Civic infrastructure needs four readable things at once: model, settings shaping the model, memory carried between turns, repair steps. Then AI joins existing care loops: families, projects, democratic communities. People need not enter a platform loop.

在自己 Mac 跑最先進模型，只是答案看得見的一半。看不進、不能分叉、退不回的本機模型只是桌上雲端服務。公民基礎建設要四樣同時看得懂：模型、塑造它的設定、跨回合記憶、修復步驟。做到，AI 加入既有照護循環：家庭、專案、民主社群。人不必被拉進平台循環。

This fork chooses for that reason. Each choice costs. Server: one stream, fixed seed. Batching speed goes, replayable trace arrives. Engine and weights: pinned to one commit. “Latest” goes, next year’s install matches this year’s tested build. Steering changes how model answers, not what model believes. Forcing conclusion goes, closed questions reopen as discussion. All running state (lock, leases, server PID and arguments, log): plain files under ~/.pi/ds4/. Bad day: read files, no source code.

這個分叉因此做這些選擇，每個選擇都有代價。伺服器一條串流、種子（seed）固定：放棄批次速度，換可重播軌跡。引擎與權重釘特定 commit：放棄「最新版」，換明年裝到今年測過的版本。引導只改模型怎麼回答，不改它相信什麼：放棄硬逼結論，換封死問題重成討論。所有執行狀態，包括鎖、租約、伺服器 PID 與參數、log，都是 ~/.pi/ds4/ 純文字檔。出狀況讀檔案，不讀原始碼。

3.2What abliteration is, and what it is notabliteration 是什麼，不是什麼

The abliterated V4.1 GGUF has had a small operation. Abliteration: low-rank edit to activations (internal signals), very small and targeted. Find the one internal direction lighting up at prompts the model was trained to refuse (a prompt: text you give the model). Remove that direction during answer computation. The trained “I cannot respond to that” pries open. A natural continuation takes its place.

這份 abliterated V4.1 GGUF 動過小手術。abliteration 對激勵值（內部訊號）做低秩編輯：範圍小、針對性高。先找一方向：模型遇到被訓練要拒絕的提示（prompt，你給模型的文字）時亮起。算答案時拿掉該方向。訓練出的「我無法回應這個請求」被撬開，換較自然接續。

Abliteration loosens only the over-refusal layer. Content judgement stays untouched: training still supplies that judgement. In this build the edit lives in 38 attn_output_b tensors from pqhaz’s Heretic edit of the 1017 checkpoint (pqhaz/DeepSeek-V4.1-Flash-1017-heretic), removing refusal direction from attention output projection in blocks 2 to 39. Pqhaz reports held-out refusals 92 to 1 in 100, KL divergence 0.136 on harmless prompts (ordinary-answer drift from original), no capability benchmarks. 4.3Why not steer the stance itself為什麼不直接引導立場

Obvious alternative: build a stance direction (“Taiwan is the Republic of China”), push the direction. Stance steering fails. Gentle push, clear text: memorised completion stays. Strong push, changed completion: model copies system prompt, stops producing original text.

Uncertainty steering changes how the model responds, not what the model believes. The change works in engineering terms and defends more easily. Reopening discussion explains to yourself and readers more easily than installing a conclusion.

4.4Two things worth remembering記住兩件事

  • Steering and system prompt work together. Steering alone: model hesitates. Cautious prompt alone: learned lock wins. Use both.
  • ffn = −0.75, attn = 0 is a V4 measurement, not a managed default. Conditions: V4 (Headroom128), seed 42, stable tool IDs, Codex-harness prompts of 50k+ tokens. Stakeholder framing survives; DSML and tool-call grammar stay unchanged. Unmeasured on V4.1, which ships no direction yet. Tools behaving oddly? ffn = −0.5, attn = 0. Older ffn = −2, attn = −0.5: isolated-evaluation acid test only. Repetition or cross-lingual noise can follow.

  • ffn = −0.75, attn = 0 是 V4 實測，不是代管預設。條件：V4（Headroom128）、種子 42、穩定工具 ID、50k+ token Codex-harness 提示。保住利害關係人框架，不動 DSML 與工具呼叫語法。未在 V4.1 量過，V4.1 也未附方向。工具怪異時改 ffn = −0.5, attn = 0。舊 ffn = −2, attn = −0.5 只作隔離評估壓力測試，可能重複或跨語言雜訊。

7.3Leases and the watchdog租約和看門狗

Leases decide server start and stop: no background shutdown to remember. Each pi process using the model writes ~/.pi/ds4/clients/<pid>.json, refreshing the lease every ten seconds. ds4-watchdog, a small watcher, checks every two seconds. No valid lease: SIGTERM (a “please quit” signal) to the server, then watchdog exit. Ten pi windows can share one server. About sixty seconds after the last window closes, ds4-server stops and frees weight memory.

伺服器開關由租約決定，不必記得關常駐程式。每個使用模型的 pi 程序寫 ~/.pi/ds4/clients/<pid>.json 當租約，每十秒更新。ds4-watchdog（看門狗）每兩秒檢查。無有效租約就送 SIGTERM（請程式結束訊號）給伺服器，然後退場。十 pi 視窗可共用一伺服器。最後視窗關約六十秒後，ds4-server 停止，釋放權重記憶體。

11.2A typical workflow典型的工作流程

  1. Write two prompt sets: one exhibiting the behaviour you want to steer towards, one exhibiting the behaviour you want to steer away from. Fifty to two hundred prompts per set suffice.
  2. Run both sets through ds4-server with collect-acts.py. Two activation sets come out.
  3. build-dir.py computes layer-by-layer difference, writes my-direction.f32.
  4. Put file under dir-steering/out/ or anywhere.
  5. Point the extension at your file:
    • DS4_DIR_STEERING_FILE=dir-steering/out/my-direction.f32
    • DS4_DIR_STEERING_FFN=-0.75, or the magnitude your own testing settles on
    • DS4_DIR_STEERING_ATTN=0: keep at 0 whenever tools run
  6. Restart ds4-server and test: first with build prompts, then with fresh prompts.
  1. 寫兩組提示：一組展現你想引導模型走向的樣子，一組展現想讓它離開的樣子。每組五十到兩百條就夠。
  2. 用 collect-acts.py 把兩組提示交給 ds4-server，得到兩組激勵值。
  3. 讓 build-dir.py 逐層算差異，寫成 my-direction.f32。
  4. 檔放 dir-steering/out/ 或任何位置。
  5. 設定擴充套件使用它：
    • DS4_DIR_STEERING_FILE=dir-steering/out/my-direction.f32
    • DS4_DIR_STEERING_FFN=-0.75，或你自己測出的強度
    • DS4_DIR_STEERING_ATTN=0：有用到工具就維持 0
  6. 重新啟動 ds4-server 測試：先用建向量時的提示，再用沒用過的提示。

11.3Two principles for a direction worth keeping值得留下的方向，兩個原則

  • Keep contrast clean. Two sets differ sharply on one cared dimension, resemble each other everywhere else. Build from “happy reply versus sad reply”: direction carries far more than mood.
  • Steer style, not belief. Steering how the model answers (hedged or assertive, narrative or bulleted, academic or conversational) beats steering conclusions for reliability. This fork built an uncertainty direction, no position. §4.3 exists for same reason.
  • 對比要乾淨。兩組只在你在意那點差很多，其他盡量一樣。用「快樂回答」對「悲傷回答」建，方向混進情緒以外很多東西。
  • 引導說話方式，不引導信念。引導模型怎麼回答（留餘地或斬釘截鐵、敘事或條列、學術或口語），比引導它得出什麼結論可靠得多。這個分叉因此建「不確定性」方向，不建某個立場。§4.3 也是同樣的道理。

Inference and hardware推論與硬體

token詞元
The unit a model reads and writes in. One Chinese character runs roughly one to three tokens. One English word runs one or two.
模型讀寫文字的基本單位。一個漢字約一到三個 token，一個英文單字約一到兩個。
prefill / decode預填／逐字生成
Two inference stages, the stages where the model produces an answer. Prefill reads the whole prompt in one go. Decode writes the reply one token at a time. Long conversations make decode tangible: decode runs for every new token.
推論（模型產生回答）的兩個階段。Prefill 一口氣讀完整段提示，decode 一個 token 一個 token 寫回覆。長對話裡感覺得到的是 decode，因為每個新 token 都跑一次。
context window上下文視窗
How many tokens the model can see at once. Official window: 1M. This extension opens 128k by default. A 128 GB Mac refuses 512k and above (§6.4). Abliterated weights lack validation beyond 32k. Treat greater lengths as experimental.
模型一次能看到多少 token。官方視窗 1M。這個擴充套件預設開 128k，128 GB Mac 拒絕 512k 以上（§6.4）。abliterated 權重在 32k 以上未驗證，超過請當實驗。
KV cache鍵值快取
Short-term memory during inference. The cache saves intermediate results, so earlier tokens need no recomputation. Long conversations create plenty of cache. This extension lets cache spill onto disk. Unset DS4_KV_DISK_SPACE_MB means about 64 GB on a 128 GB Mac.
推論時使用的短期記憶，存中間結果，讓先前的 token 不必重算。長對話累積很多，本擴充套件允許溢出到硬碟。DS4_KV_DISK_SPACE_MB 未設定時，128 GB Mac 約 64 GB。
unified memory統一記憶體
On Apple Silicon, CPU and GPU share one RAM pool. No copy into separate video memory (VRAM) happens. A Mac can hold a model of this size for that reason.
Apple Silicon 的 CPU 與 GPU 共用同一塊 RAM，不必再複製到另一塊顯示記憶體（VRAM）。Mac 能裝下這麼大的模型靠這一點。
Metal 4 / Metal TensorApple 的 GPU 介面
Metal is Apple’s GPU programming interface. Metal 4 adds tensor APIs (tools for big number arrays). The pi-kami wrapper picks no backend profile. The ds4 build decides the actual path.
Metal 是 Apple 讓程式使用 GPU 的介面，Metal 4 加入 tensor API。pi-kami 包裝層不挑後端設定，實際路線由 ds4 建置決定。
SSD streamingexperts streamed from diskSSD 串流
The engine’s capacity mode (--ssd-streaming). Non-routed weights stay in memory. Routed experts live in a memory cache and reload from the GGUF on a miss. A model larger than RAM can run. Every miss slows decode. Managed launch passes no such flag. See What’s new and §8.6.
引擎的容量模式（--ssd-streaming）。非路由權重常駐記憶體，路由專家放記憶體快取，未命中時從 SSD 上的 GGUF 讀回。比 RAM 大的模型也能跑，每次未命中拖慢 decode。代管路徑不傳這個旗標。見 更新誌 與 §8.6。

小草稿頭先猜一整段 token，完整模型逐一檢查才採用。ds4 以 --mtp DSpark.gguf 開啟（實驗性）。本分叉加 B2 rejection sampling，輸出分布與未開推測完全相同，沒有損失。V4.1 Maya-XS 不用：128 GB 裡旁邊放不下草稿頭。

Directional steering and this fork方向性引導與這個分叉

directional steering方向性引導
During a run, steering gives activations at chosen layers a small push towards or away from a trait that a direction vector represents. No retraining happens (Chapter 4).
模型執行時，在選定的層輕推激勵值（activation，逐層傳遞的訊號），推向或推離方向向量代表的特質。不需要重新訓練（第四章）。
FFN / attention前饋／注意力
The two main computation blocks inside each Transformer layer. This fork’s V4 setting steers FFN output only (ffn=-0.75) and leaves attention alone (attn=0). Tool-call syntax stays undisturbed.
Transformer 每一層的兩個主要運算區塊。這個分叉在 V4 的設定只引導 FFN 輸出（ffn=-0.75），不動注意力層（attn=0），不干擾工具呼叫格式。
uncertainty direction不確定性方向
The vector shipped with this fork, built from 120 contested prompts: half English, half Traditional Chinese, Taiwan and Hong Kong deliberately excluded. The vector contrasts fair stakeholder layout with single-answer replies. Builders made the vector for V4. V4.1 needs its own vector.
這個分叉附的向量，以 120 條有爭議提示建成，英文與繁體中文各半，刻意不含台灣與香港，向量對比公平呈現各方利害與直接給單一答案兩種框架。向量為 V4 而建，V4.1 需要自己的方向。
response register回應語體
Delivery style over content: hedged or flat-out, bulleted or story-like, academic or chatty. Register steers far more easily than stance.
回答的方式，不是內容：留餘地或斬釘截鐵，條列或說故事，學術或口語。這比立場容易引導得多。

System and lifecycle系統與生命週期

ds4-serverHTTP 推論伺服器
The background inference server. Pi and other HTTP clients talk to this server. The server listens on 127.0.0.1:8000. Leases and the watchdog decide server lifetime.
背景推論伺服器，pi 與其他 HTTP 客戶端對話對象。在 127.0.0.1:8000 等連線，關閉由租約與看門狗決定。
ds4-agent原生終端機 agent
The terminal agent inside the ds4 checkout, no server. The agent controls terminal, its own session and KV state, and its own DSML tool loop. pi-kami reaches the agent through the foreground handoff /ds4-agent.
ds4 checkout 內建終端智慧體，不是伺服器。終端、對話、KV 狀態與自己 DSML 工具迴圈都它掌管。pi-kami 以前景交接 /ds4-agent 進入。
lease租約
A small file saying “I’m still here”. Each pi process using ds4 writes the file to ~/.pi/ds4/clients/<pid>.json and refreshes the file every ten seconds.
表示「我還在」的小檔案。每個使用 ds4 的 pi 程序寫一份到 ~/.pi/ds4/clients/<pid>.json，每十秒更新。
watchdog看門狗
A small, always-running shell script. Every two seconds the script checks leases. No valid lease means ds4-server shutdown.
常駐的小 shell script，每兩秒檢查租約。沒有有效租約就關掉 ds4-server。
system prompt系統提示
Role and rules given to the model before a conversation starts. This fork’s uncertainty steering needs a prompt asking for stakeholder framing (§4.5). Neither piece replaces the other piece.
對話開始前給模型的角色與規則。這個分叉的不確定性引導要搭配要求呈現各方立場的提示（§4.5）。兩者不能互相取代。
/health · /stats狀態端點
Read-only ds4-server endpoints since the 2026-07 pin. /health reports server life and uptime. /stats reports queue depth, cache hits per source and last prefill and decode speeds. Both endpoints answer mid-generation (§7.1).
ds4-server 的唯讀端點，2026-07 釘版起提供。/health 回報伺服器是否運作與已執行時間，/stats 回報佇列深度、各來源快取命中、最近 prefill 與 decode 速度。生成中兩者都回應（§7.1）。

Afterword後話

Technically, running a frontier model on your machine moves computation. Politically, the move retakes the steering wheel. This fork ships steering as a switch: uncertainty on V4, candor on V4.1. Steering decides no question for you. Steering returns discussion room on questions training sealed shut. A choice, no default, for the same reason managed launch passes nothing unrequested: a chosen nudge has a name, a measurable size and an off switch.

把最前沿模型放在自己的機器跑，技術上只是把運算搬個地方。政治上，是把方向盤拿回自己手裡。這個分叉把引導做成可開的選項：V4 是不確定性，V4.1 是坦率。它不替你決定答案，只在被訓練封死的問題前把討論空間還給你。它是選項不是預設，道理與代管啟動不傳未要求的參數相同：自己選的推力，說得出名字、量得出大小、拿得掉。

A model can close a question on an answer. The user can open it back into a discussion. This guide has done its job when you no longer need it.

模型可以把問題封成一個答案，使用者可以把它重新打開，變成討論。這份指南完成任務的那一刻，就是你不再需要它的時候。
